# Alignment Card

Use this compact shape when the project needs a durable alignment artifact but separate requirements, design, and task documents would add little value.

```markdown
# <Change or outcome>

## Outcome

## Current facts

## In scope

## Non-goals

## Observable acceptance

## Decisions and assumptions

## Authority and external dependencies

## Next executable action
```

Keep facts, decisions, and assumptions distinguishable. Omit empty sections only when their absence cannot create ambiguity. Expand this card into separate design or task artifacts when the change develops independent milestones or interfaces.
