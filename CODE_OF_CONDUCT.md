# Code of Conduct

## Our standard

We want this project to be useful to people with different backgrounds, tools, and levels of experience. Be respectful, specific, and willing to separate evidence from opinion.

Examples of constructive participation include:

- giving actionable feedback about behavior, documentation, or tests;
- acknowledging uncertainty and correcting mistakes openly;
- respecting different technical choices when they fit the stated constraints;
- helping newcomers reproduce an issue.

Unacceptable behavior includes harassment, personal attacks, discriminatory language, deliberate disruption, publishing another person's private information, or using project spaces for unrelated promotion.

## Enforcement

Maintainers may edit, hide, or remove contributions that violate this standard and may temporarily or permanently restrict participation when necessary. Enforcement decisions should be proportional and explained when doing so would not expose private information.

## Reporting

For ordinary conduct concerns, contact the maintainers through a private channel available on their GitHub profile. If a report involves a security or privacy vulnerability, use the private process in [SECURITY.md](SECURITY.md). Do not post sensitive evidence in a public issue.

Project maintainers are responsible for clarifying and enforcing these standards in project-controlled spaces.
