# Support

Choose the channel that matches the request:

- **Usage questions and design discussion:** [GitHub Discussions](https://github.com/KKLL2025/lightweight-project-skills/discussions)
- **Reproducible defects:** use the bug report issue form
- **Scoped improvements:** use the feature request issue form
- **Security or private-path exposure:** follow [SECURITY.md](SECURITY.md) and report privately

When asking for help, include the skill name, runtime and model, operating system, original prompt, relevant output, and the smallest safe reproduction. Remove tokens, private data, and machine-specific paths first.

This is a public preview maintained on a best-effort basis. A passing repository test does not guarantee a model will follow the skill in every runtime.
